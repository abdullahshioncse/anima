INSTALLATION METHODS
================================================================================

METHOD 1: Extension Installer (Recommended)
1. Package: zip -r anima.ocmod.zip anima.ocmod/
2. Upload via: Extensions → Installer
3. Install: Extensions → Extensions → Themes
4. Configure: Edit Anima Theme settings
5. Activate: System → Settings → Theme = Anima
6. Clear cache

METHOD 2: Manual FTP
1. Upload anima.ocmod/ contents to OpenCart root
2. Set proper permissions
3. Install via Extensions → Themes
4. Configure and activate
5. Clear cache

NEXT STEPS FOR DEPLOYMENT
================================================================================

1. Package the theme:
   cd /path/to/anima
   zip -r anima.ocmod.zip anima.ocmod/

2. Upload to OpenCart:
   - Login to admin panel
   - Go to Extensions → Installer
   - Upload anima.ocmod.zip

3. Install and configure:
   - Extensions → Extensions → Themes
   - Install Anima Theme
   - Edit settings
   - Save configuration

4. Activate:
   - System → Settings
   - Edit store
   - Select Anima theme
   - Save

5. Verify:
   - Clear cache
   - Check frontend
   - Test all pages
   - Verify responsive design
   - Test checkout flow
