# Changelog

All notable changes to the Anima OpenCart Theme will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-01-04

### Added
- Initial release of Anima Theme for OpenCart 4.1.0.3
- Complete theme conversion from static HTML/CSS to OpenCart theme
- Full RTL (Right-to-Left) support for Arabic language
- Responsive design for desktop, tablet, and mobile devices
- Modern UI with Poppins font and Iconly Sharp icons
- Admin panel theme configuration page
- Multi-language support (English and Arabic)
- Complete Twig template system:
  - Header and footer templates
  - Home page template
  - Product detail page template
  - Category listing template
  - Shopping cart template
  - Search results template
  - Account management templates
  - Information pages templates
- Controller implementation with PHP 8+ namespaces
- Model implementation for theme-specific operations
- Language files for both English and Arabic
- Comprehensive documentation (README.md and INSTALLATION.md)
- Extension configuration (extension.json)
- All static assets (CSS, images, fonts) properly organized

### Features
- Top information bar with delivery, returns, and authenticity badges
- Sale banner section
- Main navigation menu with category support
- Shopping cart integration
- Wishlist functionality
- User account integration
- Search functionality
- Product cards with:
  - Wishlist button
  - Add to cart button
  - Sale and new badges
  - Product images and information
- Newsletter subscription form
- Payment method icons (Visa, Mastercard, Apple Pay)
- Social media integration
- Footer with multiple menu sections
- SEO-friendly URLs
- Cross-browser compatibility
- Performance optimized CSS

### Technical Specifications
- OpenCart Version: 4.1.0.3
- PHP Version: 8.0+
- Template Engine: Twig 3.x
- CSS Framework: Custom (based on original design)
- Icon Set: Iconly Sharp
- Font: Poppins (Google Fonts) + Plus Jakarta Display
